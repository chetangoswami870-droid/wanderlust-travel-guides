# Wanderlust — Travel Guides

A modern, responsive travel discovery website built with vanilla HTML, CSS, and JavaScript. Explore destinations, find the best time to visit, and plan unforgettable trips worldwide.

## 🌍 Features

- **Popular Destinations**: Browse curated travel destinations with detailed information
- **Advanced Filtering**: Filter destinations by category (Beach, City, Nature, Culture, Adventure)
- **Search Functionality**: Search destinations and countries in real-time
- **Best Time to Visit**: Seasonal guide with weather data and peak season information
- **Budget Breakdown**: Realistic cost estimates for budget, mid-range, and luxury travel
- **Interactive Modal**: Click on any destination to view detailed travel guides
- **Save Destinations**: Heart/favorite your preferred destinations
- **Responsive Design**: Mobile-friendly interface that works on all devices
- **Modern UI**: Clean, professional design with smooth animations

## 🎯 Sections

1. **Hero Section**: Catchy headline with search bar and category filters
2. **Popular Destinations**: Grid of destination cards with ratings and quick info
3. **Features Highlight**: Key benefits of using Wanderlust
4. **Best Time to Visit**: Month selector with weather preview
5. **Travel Guides**: Latest curated travel guides for inspiration
6. **Footer**: Navigation links and company information

## 🛠️ Technology Stack

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling with CSS variables and Grid/Flexbox layout
- **Vanilla JavaScript**: No dependencies, pure JS for interactivity

## 📱 Responsive Breakpoints

- Desktop: Full navigation and multi-column layouts
- Tablet: Adjusted spacing and grid columns
- Mobile: Single column layouts, hidden navigation menu

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/chetangoswami870-droid/wanderlust-travel-guides.git
cd wanderlust-travel-guides
```

2. Open `index.html` in your web browser or serve locally:
```bash
python -m http.server 8000
# or
npx http-server
```

3. Visit `http://localhost:8000` in your browser
